# The shared wire contract: API key auth, the OpenAI error envelope, the
# health route, Segment and OpenAISpeechRequest, the PCM byte cast, and the
# entrypoint that setuptools installs to /usr/local/bin. [audio] pulls numpy,
# which this image needs anyway.
#
# A PATH into this repository, not a tarball pinned by SHA. The pin was right
# while voice-common was its own repository: a change there reached this
# service only after a push, a tag and a re-pin, and the SHA is what made the
# build reproducible. In one repository the same pin becomes a liability — it
# lets packages/common and the services that embed it sit at different
# revisions inside a single commit, which is the one state a monorepo exists to
# make unrepresentable. The commit is the pin now, and `git log` is the only
# place either version is recorded.
#
# The path is relative to the CURRENT WORKING DIRECTORY, not to this file: pip
# resolves a path requirement against the process's cwd. Checked rather than
# assumed — reading this file from its own directory fails with "Expected
# package name at the start of dependency specifier", which reads like a syntax
# error in the file and is not one. So every install runs from the repository
# root, which is what the Containerfile's WORKDIR and every CI job do.
./packages/common[audio]
