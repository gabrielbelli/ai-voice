# dictation — mishearings of ordinary speech that any dictating user hits.
#
# Two line forms, because they are two different jobs:
#
#   heard = intended     a replacement AND a hotword
#   Term                 a hotword only
#
# Use the bare form when the likely mishearing is an ordinary word. "Belli" is
# heard as "belly", but a `belly = Belli` rule would corrupt any sentence that
# genuinely says belly. Biasing the decoder is safe; rewriting is not.
#
# NOTHING HERE IS ANYONE'S PROJECT NAME. This file ships in a public image, so
# a term that only one person ever says would be applied to strangers' audio to
# fix a word they have never used — and it is not free either: measured across
# 25 cells, a glossary whose terms do NOT occur in the audio raised WER by
# 28% on Whisper, and nothing measurable on Parakeet. Personal vocabulary goes in a
# deployment-supplied profile; see examples/glossaries/personal.txt.
